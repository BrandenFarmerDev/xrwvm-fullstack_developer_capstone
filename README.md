# fullstack_developer_capstone

Best Cars is a full stack car dealership review application for IBM CAD0321EN.

The project combines Django authentication and car inventory models, a React frontend,
Express/MongoDB dealership and review APIs, sentiment analysis, CI, and container deployment.

Implementation and runtime validation are in progress. No completion is claimed until
the corresponding course requirements have been independently checked.


The team names, roles, biographies, and contact information are fictional course
examples. Portrait photographs are from Unsplash (image identifiers
1494790108377-be9c29b29330, 1500648767791-00dcc994a43e, and
1534528741775-53994a69daeb). Starter code and provided assets are from IBM's
`ibm-developer-skills-network/xrwvm-fullstack_developer_capstone` repository.
